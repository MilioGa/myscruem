# MySCruEm 1.0

Versión final del proyecto, integrada al cierre del sprint 5.

## Funciones

- Empresas, usuarios, roles, invitaciones y equipos.
- Proyectos, Product Backlog, historias de usuario, épicas, prioridades y estimación.
- Sprints con planificación, inicio y cierre; Sprint Backlog y tareas.
- Tablero Kanban con filtros, impedimentos y gráfico Burndown.
- Material de capacitación en Scrum con guía, infografías y glosario.
- Sprint 5: Definition of Done, notificaciones, velocidad del equipo, comentarios y adjuntos en tareas, y actas de eventos.

## Integración

- Regresión completa con `npm test`: todas las pruebas aprobadas.
- Migración probada desde bases de los sprints 3 y 4.
- Revisión de seguridad documentada en `docs/seguridad.md`.
- Manual de usuario en `docs/manual-usuario.md` y guion de demostración en `docs/demo-final.md`.

## Instalación

Requiere Node.js 24 o superior.

```
npm install
npm run demo
npm start
```
